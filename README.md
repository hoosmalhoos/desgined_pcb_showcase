# First Design in KiCad (first_design_in_kicad_Y1)

Welcome to the repository for my very first custom PCB design, created using KiCad! This repository contains the Gerber files required for manufacturing and documents my journey from schematic capture to holding a physical printed circuit board.

---

## 📸 Project Overview

- **Project Name:** `first_design_in_kicad_Y1`
- **Design Tool:** [KiCad EDA](https://www.kicad.org/)
- **Status:** Designed & Fabricated 🟢
- **Description:** A beginner-friendly PCB design developed to learn board layout, routing, ground planes, and preparing production output files (Gerbers).

## 🏭 How to Get This PCB Manufactured Physically

If you want to fabricate this board using services like **JLCPCB**, **PCBWay**, **OSH Park**, or similar fabricators:

1. Download or clone this repository.
2. Compress the contents of the `gerbers/` folder into a single `.zip` file (if not already zipped).
3. Go to your preferred PCB manufacturing site and upload the `.zip` file.
4. Review the board preview generated by their Gerber viewer.
5. Choose your board preferences (color, thickness, surface finish) and place your order!

## 🧠 Key Learnings from this Project

Building **`first_design_in_kicad_Y1`** helped me learn essential PCB design concepts:
- Navigating the KiCad schematic and PCB layout workflow.
- Assigning footprints to components and setting up design rules (DRC).
- Manual routing and adding ground fills (pours).
- Generating Gerber and Drill files according to industry standards.
